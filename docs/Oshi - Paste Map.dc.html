Oshi — Code Index

A map of what lives where in Oshi Survey & Retrospective.dc.html and where each piece lands in clarity-loop/. The prototype file is the source of truth — Claude Code reads and ports directly from it. Everything below is referenced by name (constant / method / element), never by line number, so it stays valid as the file is edited.
How to use this with Claude Code. Hand over the prototype .dc.html and the Spec, then point Claude Code at this index. It tells it where each block is (search by the named anchor) and what to do with it: copy verbatim, port templating → DOM, or rewire I/O. No manual copy-paste required.
Server-side narration is already built. The whole Oshi voice layer — persona, per-screen prompt assembly, the ||| reflection, guardrails, scripted fallbacks — now lives in the backend/orchestrator/oshi/ package (OshiNarrator). Wherever §D/§E below say to build _oshi_line() or move _contextFor/_makeReflection server-side, that is done: wire main.py to OshiNarrator per oshi/README.md. agent.py's only job stays the intervention selector (_call_haiku).
